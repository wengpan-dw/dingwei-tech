BMS 定位器

自主研发 4G BMS 跟踪器主板，支持段码液晶显示与触摸按键，集成 SPEAKER 和 485 通讯接口。
兼容主流锂电/铅酸 BMS 通讯协议，实时采集电池电压、温度、SOC、循环次数等数据，
通过 4G 网络上传至云端平台，实现电池全生命周期管理。

4G 智能中控

集成 GPS 实时定位、蓝牙通信、姿态检测、防盗报警等功能。
通过 4G 网络和蓝牙分别与云端平台、手机 APP 进行数据交互，
实时上传车辆状态至服务器，支持远程控车、电子围栏、轨迹回放。
安装简便，只需线束对插即可完成升级。

9DOF 惯性传感模组

9 轴（3 轴加速度 + 3 轴陀螺仪 + 3 轴磁力计）惯性测量单元，
内置姿态解算算法，支持 AHRS 航姿参考。
适用于车辆姿态检测、碰撞识别、运动轨迹分析等场景，
提供 I²C / SPI / UART 多种接口，方便嵌入式集成。

AIOT 物联平台

自研物联网云平台，支持百万级设备并发接入。
提供设备管理、数据可视化、远程 OTA 升级、异常告警等功能。
支持 MQTT / CoAP / HTTP 协议，可对接主流第三方平台，
为智慧出行、资产追踪、能源管理提供数据底座。

二轮车 BMS 定位方案

针对电动自行车/摩托车换电与共享出行场景，集成 4G 定位 + BMS 数据采集，
实现电池状态实时监控、异常预警、远程锁车等功能

设备物联定位方案

为工业设备、物流载具、工程机械提供 4G 定位终端，
支持 GPS / BDS / GLONASS 多模定位，结合电子围栏与轨迹回放，实现资产全程可追溯

惯性导航方案

基于 9DOF IMU 的惯性导航与姿态感知方案，
适用于 GNSS 信号遮挡环境（隧道、地库），提供高精度航位推算与碰撞检测
